👾 Sobre mí

Soy Pablo, aunque casi todo el mundo me conoce como PapiGEGamer. Me gusta construir proyectos que mezclan desarrollo web, comunidades, herramientas y experimentación técnica.

🌐 Desarrollo con React, TypeScript, Next.js y Vite.

💬 Creo integraciones para Discord, APIs y sistemas en tiempo real.

🎮 Me interesan el gaming, el modding, las redes P2P y los proyectos poco convencionales.

🤝 He participado en gran parte del ecosistema FNLB y en varios proyectos de Kira Kohler.

🧪 Siempre tengo alguna prueba de concepto, herramienta o sistema que mejorar.

🌙 Fuera del código: Valorant, música, anime y personalizar Discord hasta el último detalle.

FOCUS    web · tools · integrations · communities
MODE     learning · experimenting · building
